# Split-Expenses

This is expense splitting backend based on FastAPI.

# What we will do in split expense? (basics)

1. user creates account.
2. user will create a group and add other users
3. user will add expenses in group and select who paid and who will pay.
4. money get divided between user accordingly.
5. other user can also add expenses.
6. expense will be caculated accordingly and show the final price who have to give what.
